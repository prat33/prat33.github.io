# 🎰 Pratheek N — Jackpot Resume

My interactive resume, styled like a casino slot machine.

**Live site:** https://prat33.github.io

## Features

- **Spin my stats:** a working slot machine that reveals career highlights
- **Neon casino theme:** marquee bulbs, a scrolling ticker, and skill "chips" on a poker table
- **Responsive:** works on desktop and mobile
- **Accessible:** respects reduced-motion settings and supports keyboard navigation

## Built with

Plain HTML, CSS, and JavaScript in a single `index.html`, with no frameworks or build step. Fonts are from Google Fonts.

## Run locally

Download or clone the repo and open `index.html` in any browser.
